# 七种测量语言 · 设计方案

> Retro Dock 1.4 设计研究。七套仪表语言共用同一份数据合同：`≈ tok/s`、CTX、HIT，以及 live / warn / over / stale / DOM 五种状态。改变的是**测量机构、表面、字体与运动**，不是换一组颜色。

## 一、判断

现役经典双表盘的问题不是不精致，而是只有一种性格：一枚透明、轻、正确的仪器。它适合常驻，但没有回答「这台工具应该像什么」。上一版四套样式把仪器压成卡片里的小图标，四种语言只在弧线颜色上分开，所以不成立。

这一版的原则：

1. **一个活动件。** 每一套只让一个部件承担速度：刀锋针、VU 针、鼓形计数器、臂板、走纸笔、方块游标、罗经卡。速度的「动」就是这套语言的身份。
2. **红色只给界限。** 七套都保留警戒线 / 过速的红色语义；没有一套用红色做品牌装饰。HIT 不是警告，永远不红。
3. **表面要么属于仪器，要么完全不存在。** 台表、VU、高度表、信号楼、记录纸各自拥有面板；瑞士尺与罗经只借宿主，不画底板。没有「白字浮在白底」的第三种状态。
4. **真实 1× 优先。** 输入位 56px、统计条 42px 是验收尺寸；3× 只用于检查刻线、字距与表面工艺，不拿来假装尺寸。
5. **运动是机构运动。** 不加入场动画、不滚动淡入、不做悬浮卡片。唯一允许的「非数据运动」是暗色下的灯丝余温，且不循环。

## 二、七套语言

### 1. 台表 · Bench

| | |
| --- | --- |
| 传统 | 实验室台式万用表、校准台 |
| 表面 | 冷锌灰面板（深色为石墨），内嵌读数窗 |
| 机构 | 240° 刻线 + 刀锋针；CTX 细环；红色只出现在警戒刻线与过速点 |
| 字体 | Bahnschrift（DIN 1451 技术体） |
| 运动 | 临界阻尼，不做过冲；过速时针停在止挡，端点红点亮 |
| 适合 | 想要「精确、安静、有一点点机械」的默认形态 |

面板是矩形，读数窗凹进去 1px；刻度数字只留 0 / 90 / 180，其余交给读数。它不是复古手表，是一台需要读数的台表。

### 2. 广播 VU · Broadcast VU

| | |
| --- | --- |
| 传统 | 1950s 广播 VU 表 |
| 表面 | 象牙色表盘、深青铜压边；暗色下是「亮着的表」，不是暗表 |
| 机构 | 130° 宽扇区 + 楔形针；末端红区；CTX/HIT 刻在表盘下沿 |
| 字体 | Constantia（刻度）+ Bahnschrift（读数） |
| 运动 | 轻微过冲，像一根有质量的针；过速时峰值灯亮 |
| 适合 | 长时间陪伴；希望数字有一点温度 |

面板始终是暖的，在深色宿主里是一块小面积的灯。红区是印刷在表盘上的，不是报警时才出现。

### 3. 气压高度表 · Altimeter

| | |
| --- | --- |
| 传统 | 飞机气压高度表 / 马赫表 |
| 表面 | 浅灰仪表面板 + 黑色表盘 + 黑色鼓形计数器（两种主题都保留黑窗） |
| 机构 | 270° 细白针 + 三位滚动数字；CTX 是下方细条 |
| 字体 | Bahnschrift Condensed（数字优先） |
| 运动 | 指针平滑，数字逐位滚动；过速时红色止挡标记亮 |
| 适合 | 只想知道「多少」，不想读表盘 |

读数窗是主角，环只提供方位感；数字滚动是这套语言唯一允许的「机械感」。

### 4. 信号楼 · Signal

| | |
| --- | --- |
| 传统 | 铁路臂板信号机、闭塞仪 |
| 表面 | 象牙搪瓷 / 黑搪瓷面板，随主题反转 |
| 机构 | 臂板从水平抬到 72°；CTX 用绿 / 琥珀 / 红三枚灯表示状态；HIT 是计数器 |
| 字体 | Bahnschrift |
| 运动 | 臂板随速度抬起；灯在阈值处瞬切，不做渐变 |
| 适合 | 先看清「有没有到警戒」，再读具体数值 |

它是七套里唯一把 CTX 做成**离散状态**的：灯告诉你状态，数字告诉你多少。警告不依赖颜色记忆，灯的位置固定。

### 5. 走纸记录 · Chart

| | |
| --- | --- |
| 传统 | 走纸记录仪、地震仪 |
| 表面 | 浅色记录纸；暗色下是蓝黑记录纸，不是白纸硬贴在深色上 |
| 机构 | 20 秒历史轨迹 + 当前点；CTX 是右侧批注栏的竖向压力条 |
| 字体 | Consolas（数字/坐标）+ Segoe UI（批注） |
| 运动 | 纸向左走，笔在右缘；每个采样一步，不插值 |
| 适合 | 长生成时用余光看「还在不在动、是不是掉速了」 |

速度第一次变成**走势**而不是瞬间值。没有历史时不伪造历史：左半张纸是空的，轨迹从挂载那一刻开始长。

### 6. 瑞士尺 · Swiss

| | |
| --- | --- |
| 传统 | 瑞士信息设计、测量尺 |
| 表面 | 无表面，只借宿主纸面 |
| 机构 | 数字 + 发丝标尺 + 6px 方块游标；CTX 是第二条短尺 |
| 字体 | Arial（Helvetica 的 Windows 替身），紧字距、表格数字 |
| 运动 | 游标 120ms 线性跟随；没有针、没有弧、没有灯 |
| 适合 | 最安静的一种；只想要一条读数，不想要一台机器 |

它不是「极简皮肤」，而是一套信息排版：读数、标尺、阈值刻线、辅助读数各占一条基线。红色只出现在越过阈值的游标上。

### 7. 罗经复示 · Compass

| | |
| --- | --- |
| 传统 | 船用陀螺罗经复示器 |
| 表面 | 深海军蓝罗经卡 + 黄铜压圈；读数在卡外，跟随宿主 |
| 机构 | 罗经卡旋转，固定基准线读数；CTX 是固定外环；HIT 是铜牌计数 |
| 字体 | Cambria（读数）+ Bahnschrift（卡面刻度） |
| 运动 | 整张卡旋转，固定基准线不动；过速时基准线端点变红 |
| 适合 | 想要一个安静但持续在动的对象 |

七套里唯一让「整个面」旋转的：不是针在动，是你在地图上转。

## 三、目录页

目录页本身是一本**仪器样张册**，不是七张卡片：

- 纸面：冷灰 `#ECEBE6`，墨 `#161817`，发丝线 `rgba(22,24,23,.16)`，登记红 `#B83A26` 只用于索引刻记与推荐标记。
- 字体：Bahnschrift 做大写标题与仪器名，Segoe UI / 微软雅黑做正文，Consolas 只用于规格数字。
- 首屏是「七台仪器同台」：浅色与深色两条真实 1× 仪器带，先看整体，再进入单页。
- 每套占一个跨页：左侧是传统、机制、表面、字体、运动；右侧是 56px 输入位（浅/深）、42px 五种状态、3× 细节。文字左右交替，不做等大卡片。
- 收尾是 42px minimal 密度七连排 + 一句推荐，不放评分表。

## 四、共同验收

- 1× 下读数 ≥ 4.5:1；承担读数的弧 / 针 / 数字 ≥ 3:1。
- 警戒、过速、DOM / stale 在 1× 有非颜色的第二线索（刻度、灯、角标、止挡）。
- live ↔ idle 不产生水平位移；`≈` 有固定槽位。
- 键盘焦点可见；`prefers-reduced-motion` 下所有机构落到目标值。
- 浅色与深色各自成立，不靠黑色预览台伪装。
- 七套都跑同一组 `scale / warnAt / sub / density / placement`，不是七套硬编码读数。

## 五、落地

- 机构：`src/ui/designs/{bench,vu,altimeter,signal,chart,swiss,compass}.js`；共享 shell 在 `src/ui/design-gauge.js`，几何与 `Drum` 在 `src/ui/designs/kit.js`。
- 样式：`src/styles/designs/*.js`，共享 shell 在 `src/styles/designs/base.js`；所有选择器都收在 `.rg-gauge[data-style="…"]` 下。
- 选择：`prefs:v3` 的 `style` 字段；设置页用 42px 真实预览；默认仍是 `classic`，更新不会静默换掉用户现有的仪表。
- 目录：`docs/catalogue.html`；`npm run catalogue` 生成，`npm run catalogue:shots` 生成 `docs/seven-languages*.jpg`。页面在 1440px 下渲染 91 个真实 1× 实例。
- 对比度：主/次级文字均 ≥4.5:1；承担读数的弧、针、灯与界限 ≥3:1。浅色信号楼琥珀灯改为 `#965812`（4.3:1），浅色高度表界限红改为 `#A63122`（5.0:1），黑窗上的过速标记改用单独的亮红。
- 测试：67/67（1.5.0）；七套机构 SSR、设置预览、jsdom 样式切换与 meter loop 重新挂载、构建产物契约。
