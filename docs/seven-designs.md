# 四种测量语言

> Retro Dock 1.6。四套外观共用同一份数据：`≈ tok/s`、CTX、HIT，以及 live / warn / over / stale / DOM。改变的是测量机构，不是换一组颜色。

## 去留

1.6 把八个选项收成四个。每个选项对应一种阅读需求，而不是一种材质。

| 保留 | 需求 |
| --- | --- |
| **经典**（默认） | 综合读数：针 + 数字 |
| **广播 VU** | 长时间陪伴；针有一点过冲 |
| **记录纸** | 看 20 秒走势和掉速 |
| **瑞士尺** | 最安静：数字 + 发丝尺 |

收进共享选项，而不是单独成套：

- **鼓轮读数**（来自高度表）：`readout: drum`，用于经典和 VU
- **上下文三灯**（来自信号楼）：`ctxLamps`，绿 / 黄 / 红；未知时全灭
- **台表**与经典几何相同（150° 起点、240° 扫角），不再单列
- **罗经**下架：卡在转，卡上没有可读的速度

## 原则

1. 每一套只让一个部件承担速度。
2. 红色只给界限：CTX 警戒、满量程、过速。过期角标用中性虚线「停」，不再用「!」。
3. 表面要么属于仪器（VU、记录纸），要么完全不存在（瑞士尺、经典）。
4. 验收尺寸：输入位 56px，统计条 42px；文字不小于 7.5px。
5. 运动是机构运动。VU 轻微过冲；其余过阻尼；碰到止挡就停。

## 四套

### 经典

240° 量程、锥形针、CTX/HIT 副表。CTX 未知时轨道画虚线。过速加粗末端刻度，不再用青色辉光。可选鼓轮和三灯。

### 广播 VU

象牙表盘、宽扇区。红区固定在量程 90–100%（过速），CTX 警戒只出现在侧读数和 `!`。深色下空闲压暗，生成中才亮。

### 记录纸

20 秒走纸。笔迹是蓝黑墨水；红色只给满量程虚线和过速点。减少动态时 1 Hz；标签页隐藏时不采样。

### 瑞士尺

数字、实墨发丝尺、方块游标。完全借用宿主字体与墨色。CTX 未知时短尺变虚线、藏游标。
